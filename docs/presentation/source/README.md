# Presentation source

`RAG_PDF_Chatbot_Capstone.pptx` (one level up) is generated by `build_deck.js` from `deck_data.json`.
Every number in `deck_data.json` is copied from `docs/evaluation_report.md`; if you change a judgement
there, update `deck_data.json` and rebuild, or edit the .pptx directly in PowerPoint.

Rebuild (Node 18+):

```bash
cd docs/presentation/source
npm install pptxgenjs          # once
NODE_PATH=$PWD/node_modules REPO=../../.. PPTX_SKILL=<path to a pptx skill providing scripts/apply_theme.js> node build_deck.js
```

`apply_theme.js` only writes the theme colours/fonts into the file; without it, open the deck in
PowerPoint and the content is unchanged but scheme colours fall back to Office defaults.

`overflow.py` is a rough text-fit estimate (wraps text with the Office Calibri/Cambria metrics). All slides
were rendered with LibreOffice and checked visually (2026-11-19). The UI slide uses `ui_screenshot.png`,
captured from the running app.
